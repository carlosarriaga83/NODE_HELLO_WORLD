POST/v1/messages

Envio desde la cuenta vinculada a tu API key. El numero debe incluir codigo de pais y no lleva +.

terminal
curl -X POST https://wa.2api2.com/v1/messages \
  -H "X-API-Key: $WA_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"to":"5215512345678","text":"Hola desde mi integracion"}'
Python + requests
import os
import requests

response = requests.post(
    "https://wa.2api2.com/v1/messages",
    headers={"X-API-Key": os.environ["WA_API_KEY"]},
    json={"to": "5215512345678", "text": "Hola desde Python"},
    timeout=20,
)
response.raise_for_status()
print(response.json())

PROMPT PARA AGENTE EXTERNO

Integra WA Control

Integra la API REST de WA Control para enviar mensajes de WhatsApp autorizados.

Base URL: https://wa.2api2.com
Autenticacion: lee WA_API_KEY desde variables de entorno y enviala como encabezado X-API-Key. Nunca pongas la clave en codigo, URLs, logs ni respuestas al usuario.

Enviar: POST /v1/messages con Content-Type: application/json y cuerpo {"to":"NUMERO_INTERNACIONAL_SIN_MAS","text":"MENSAJE"}. El numero debe tener de 8 a 15 digitos, incluir codigo de pais y no usar +, espacios ni guiones.

Respuestas: 201 indica envio correcto; 400 datos invalidos; 401 clave ausente o invalida; 409 cuenta de WhatsApp no conectada. Maneja errores y define timeout de 20 segundos.

Logs: GET /v1/messages?limit=1..100 requiere tanto X-API-Key como X-Log-Access-Token. El token se obtiene solo despues de desbloquear Log dentro del dashboard con el codigo enviado a WhatsApp y expira en 15 minutos. No intentes omitir este paso.

Escribe una integracion pequena, sin dependencias innecesarias, usando variables de entorno y mostrando errores accionables.

Elige el metodo que prefieras. Ambos vinculan la misma cuenta de WhatsApp.

El codigo es temporal. Si expira, solicita otro con el mismo numero.
